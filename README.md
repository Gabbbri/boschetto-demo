# Sport Chalet Boschetto — sito statico

Questo pacchetto contiene HTML, CSS, JavaScript e immagini. Non serve installare nulla o eseguire una build.

## Pubblicazione su GitHub Pages

1. Crea un repository GitHub, per esempio `boschetto-demo`.
2. Carica **il contenuto di questa cartella** nella radice del repository: `index.html`, `styles.css`, `site.js`, `.nojekyll` e la cartella `assets/`. Non caricare lo ZIP come unico file.
3. Nel repository apri **Settings → Pages**. In **Build and deployment** seleziona **Deploy from a branch**, poi `main` e `/(root)`, e salva.
4. Il sito sarà raggiungibile all'indirizzo indicato da GitHub Pages, di norma `https://TUO-UTENTE.github.io/boschetto-demo/`. Puoi configurare in seguito un dominio personalizzato.

I collegamenti a Instagram, WhatsApp e Google Maps aprono servizi esterni. Il logo Facebook non è collegato. Gli orari e gli eventi attuali sono contenuti demo: verifica testi, date, immagini, indirizzo e numero prima di mostrarlo come sito definitivo.
